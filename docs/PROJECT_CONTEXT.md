# MediKiosk - Project Context

## Project Information
- **Project Name:** MediKiosk
- **SIH Problem Statement:** SIH26047
- **Project Type:** AI-Powered Clinical Intake & Clinical History Software Platform

## Project Objective
MediKiosk is an AI-assisted clinical intake and documentation platform designed to streamline the patient intake process in healthcare facilities. The platform aims to reduce doctor workload by automating initial clinical interviews and documentation while maintaining strict medical safety standards.

## Core Workflow (Future)
1. Patient Authentication
2. Profile Management
3. Informed Consent
4. Multilingual Selection
5. AI-Guided Clinical Interview
6. Multi-Modal Input (Voice/Text/Touch)
7. Speech Recognition (Sarvam ASR)
8. Local LLM Processing (Qwen3 1.7B via Ollama)
9. Clinical Information Extraction
10. Medical Report Upload & OCR
11. AI Clinical Summary Generation
12. Clinical Priority Assessment
13. Doctor Review & Verification
14. Final PDF Generation
15. Secure Patient Delivery
16. Smart Follow-Up Scheduling

## Major System Components
- **Frontend:** React-based web application with responsive design
- **Backend:** FastAPI-based REST API
- **Database:** MongoDB for flexible document storage
- **AI Services (Planned):** Local LLM, ASR, TTS, OCR

## Technology Stack
- **Frontend:** React, Vite, Modern CSS
- **Backend:** Python, FastAPI, Uvicorn, Pydantic
- **Database:** MongoDB with Motor (async driver)
- **AI (Future):** Qwen3 1.7B (Ollama), Sarvam ASR, OCR Pipeline

## Current Development Phase
**Phase 1 - Foundation** (Current)
- Project structure setup
- Basic frontend/backend scaffolding
- Health check endpoints
- Documentation foundation

## Important Project Rules
1. AI is ASSISTIVE only - never autonomous
2. Doctor verification is mandatory
3. No medical decisions without human review
4. Patient data security is critical
5. Multilingual support is essential
6. Accessibility-first design

## Future Feature Roadmap (High Level)
- Authentication & Authorization
- Patient Management
- AI Interview System
- Voice/Text Processing
- Clinical Documentation
- Doctor Dashboard
- Report Generation
- Follow-up System
